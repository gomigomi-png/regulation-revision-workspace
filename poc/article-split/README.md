# PoC-2: 条文分割

## 目的

貼り付けた規程全文を、`第○条` を目印に条文候補へ分割できるか確認する。

## 確認したいこと

- 規程全文テキストを入力にできる
- `第1条（目的）` のような条文見出しを検出できる
- 章見出し、条文、附則、別表を別ブロックとして検出できる
- ラベル、見出し、本文を持つJSONにできる
- 旧文と新文の初期値を同じ内容にできる
- 規程内の表示順を保てる

## 実行方法

```bash
node poc/article-split/split-articles.mjs
```

## 入力

```text
poc/article-split/sample-regulation.txt
```

## 出力

```text
poc/article-split/generated/articles.json
```

## 初回PoCの見方

このPoCは、規程構造解析の完全性ではなく、作業用の下書きとして使えるかを確認する。

現時点では、以下を別ブロックとして扱う。

- `第○章`
- `第○条`
- `附則`
- `別表○`

本文がない章見出しも、規程順を保つため独立ブロックとして保持する。
